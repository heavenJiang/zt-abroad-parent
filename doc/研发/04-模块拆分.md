| `abroad-system` | 员工账号、角色权限、审计日志、字典、事件表 | common | 1a |

| `abroad-crm` | 客户、线索、跟进、分配、SLA、渠道归因、简单统计 | common、system、ai、integration | 1a |

## 1a 功能点与验收标准

每个功能点对应开发计划里的一张或几张任务卡；验收标准就是任务卡的验收标准。**不在表里的功能 1a 不做。**

### 系统（system）

| 功能点 | 验收标准 |
| --- | --- |
| 员工登录 | 账号密码登录；连续 5 次失败锁定 15 分钟；令牌过期可刷新 |
| 角色与权限 | 预置「负责人 / 顾问 / 数据录入」3 个角色；顾问只看得到分配给自己的线索；无权限接口返回 403 且界面不显示入口 |
| 租户字段 | 所有业务表写入时自动填 `tenant_id`，查询自动带条件；有测试证明改不了其他租户数据 |
| 审计日志 | 登录、查看手机号全文、导出、修改权限均有记录，负责人可查询 |

### 院校库（catalog）

| 功能点 | 验收标准 |
| --- | --- |
| 院校与项目录入 | 可增删改查；按国家、学位、学科大类筛选；每个项目可按申请季录入要求 |
| 字段来源 | 均分、语言、截止日等关键字段保存时必须填来源 URL；列表显示核对日期，超过 90 天标黄 |
| AI 预填 | 粘贴官网链接后 30 秒内预填字段并附原文引句；录入者确认后才保存；抓取失败有提示 |
| 批量导入 | 提供 Excel 模板；导入前预览、标出错误行；重复项目不重复创建 |
| 国内高校层次表 | 从种子文件导入；支持别名（如校名简称）；问卷输入校名可模糊匹配 |

### 测评与选校（assessment）

| 功能点 | 验收标准 |
| --- | --- |
| 问卷定义 | 问卷由 JSON 定义（题目、选项、校验、跳过规则），按版本管理；改问卷不需要发版 |
| 答题与断点 | 每步自动保存；关闭后重新打开从上次位置继续；未登录也能答题 |
| 简历解析 | 上传 PDF / 图片简历，预填学校、专业、均分、经历条目；学生可修改；解析失败不影响手填 |
| 归一化 | 按产品文档「输入维度」一节把答案转为 0–100 子分；4 分制与百分制、托福与雅思换算有单元测试 |
| 选校引擎 | 实现硬门槛、综合分 C、录取可能性 P、冲 / 稳 / 保分档、偏好排序、差距反算；同一输入多次计算结果完全一致；单次计算 1 秒内；全部引擎测试用例通过 |
| 引擎配置 | 负责人可在管理端修改权重、阈值、参考线，保存为新版本；每条结果记录使用的引擎版本 |
| 引擎测试台 | 管理端可批量跑已知结果的历史案例，显示每档命中率 |
| 报告 | 结构化结果 2 秒内展示；AI 解读异步补充，失败时用模板文字；不显示百分比；含数据来源与免责说明 |
| 分享长图 | 默认不含姓名、本科学校、具体均分；带工作室二维码与渠道码 |

### CRM（crm）

| 功能点 | 验收标准 |
| --- | --- |
| 客户查重 | 同一 unionid 或手机号只有一个客户；重复测评归到同一客户 |
| 线索自动创建 | 完成测评后 10 秒内出现在线索列表，带渠道、测评摘要、意向度 |
| 意向度 | 按可配置规则计算 A / B / C；顾问可手动修改并记录原因 |
| 分配 | 支持手动分配和轮询；分配后 1 分钟内企微通知顾问 |
| 线索列表与详情 | 列表按意向度和 SLA 排序，可筛选；详情抽屉显示客户、测评结果、AI 线索卡片、跟进时间线 |
| 跟进与阶段 | 记录跟进；阶段：初联 / 首访已约 / 方案已出 / 签约 / 流失；流失必填原因 |
| SLA 提醒 | A 类 2 小时未联系提醒顾问，再超 2 小时提醒负责人；时长可配置 |
| 渠道码 | 可生成带渠道码的链接和二维码；统计每个渠道的测评数、完成数、线索数、签约数 |
| 简单统计 | 一页展示本周 / 本月的测评、线索、签约与渠道排名 |

### AI 与对接（ai、integration）

| 功能点 | 验收标准 |
| --- | --- |
| AI 网关 | 按「架构设计·AI 网关」的 8 步实现；主模型不可用时自动切备用；每次调用都有日志 |
| 提示词与评测 | 从 `prompts/` 加载；一条命令跑完指定 Agent 的评测样例并输出报告 |
| 调用日志查看 | 负责人可按 Agent、时间、状态查看，并统计每天 token 与费用 |
| 微信登录 | 小程序一键登录拿到 openid / unionid；H5 用微信网页授权 |
| 企微通知 | 线索分配、SLA 提醒通过企微应用消息发给顾问，点击打开线索详情 |
| 加顾问企微 | 报告页展示负责顾问的「联系我」二维码；学生添加后自动关联到客户 |
| 企微侧边栏 | 顾问在企微聊天中打开，显示该客户的测评结果、线索卡片，可记跟进 |
| 文件存储 | 上传到私有存储桶；访问链接 10 分钟内有效 |

## 1a 接口清单

下表是接口范围，请求和响应字段由对应任务卡在 OpenAPI 里定义。

**学生端 `/app/api`**

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/assessment/questionnaire/current` | 取当前问卷定义 |
| POST | `/assessment` | 同意隐私政策后创建测评（带渠道码、请求 ID） |
| PUT | `/assessment/{id}/answers` | 分步保存答案 |
| POST | `/assessment/{id}/resume` | 上传简历并触发解析 |
| GET | `/assessment/{id}/resume-parse` | 取解析结果（轮询） |
| GET | `/cn-university/search` | 国内高校模糊搜索 |
| POST | `/auth/wechat` | 微信登录，返回学生端令牌 |
| POST | `/assessment/{id}/submit` | 提交并同步返回结构化结果 |
| GET | `/assessment/{id}/report` | 取报告（含 AI 解读状态） |
| POST | `/assessment/{id}/share-image` | 生成分享长图 |
| GET | `/assessment/{id}/advisor` | 取负责顾问的企微二维码 |
| POST | `/booking` | 预约顾问解读 |

**管理端 `/admin/api`**

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/auth/login`、`/auth/refresh` | 登录、刷新令牌 |
| CRUD | `/system/users`、`/system/roles` | 员工与角色 |
| GET | `/system/audit-logs` | 审计日志 |
| CRUD | `/catalog/schools`、`/catalog/programs` | 院校与项目 |
| CRUD | `/catalog/programs/{id}/requirements` | 按申请季的要求（含字段来源） |
| POST | `/catalog/programs/ai-prefill` | 粘贴官网链接，AI 预填 |
| POST | `/catalog/import` | Excel 批量导入（预览 + 确认两步） |
| CRUD | `/catalog/cn-universities` | 国内高校层次表 |
| CRUD | `/assessment/questionnaires` | 问卷版本 |
| CRUD | `/assessment/engine-configs`、`/assessment/benchmarks` | 引擎权重、阈值、参考线 |
| POST | `/assessment/engine-test` | 批量跑测试案例并返回命中率 |
| GET | `/crm/leads`、`/crm/leads/{id}` | 线索列表与详情 |
| PUT | `/crm/leads/{id}/stage`、`/crm/leads/{id}/assign`、`/crm/leads/{id}/intent` | 改阶段、分配、改意向度 |
| POST | `/crm/leads/{id}/follow-ups` | 记录跟进 |
| CRUD | `/crm/channels` | 渠道码与二维码 |
| GET | `/crm/stats` | 简单统计 |
| GET | `/ai/call-logs`、`/ai/usage` | AI 调用日志与用量 |

**外部回调与企微侧边栏**：`/callback/wecom`（企微事件，含客户添加顾问）、`/wecom-sidebar/api/customer`（侧边栏取当前客户信息，用企微身份鉴权）。
