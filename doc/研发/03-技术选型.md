# 技术选型

## 选型结论（2026-10-13 定稿：沿用 RuoYi 脚手架）

**沿用 RuoYi 脚手架（与 zt-vision-parent / zt-vue 同一套）、单体应用、单台服务器起步。** 权限、菜单、字典、日志、定时任务、代码生成直接复用；与原方案的差异见 [00-RuoYi落地对照.md](00-RuoYi落地对照.md)。

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 后端 | JDK 17 + Spring Boot 4.1 + RuoYi-Vue 3.9.2（`zt-abroad-parent`） | Maven 多模块：RuoYi 基础模块 + 业务模块 `zt-abroad`，单体部署 |
| 数据访问 | MyBatis + XML + PageHelper | 单表 CRUD 用代码生成器 |
| 数据库 | PostgreSQL 15 | 1b 需要向量检索时评估 pgvector |

| 缓存 / 限流 / 轻队列 | Redis | 异步任务用 Redis 或数据库任务表，不引入独立消息队列 |
| 定时任务 | Quartz（RuoYi 定时任务管理） | SLA 提醒、院校信息检查 |
| 微信 / 企业微信 SDK | WxJava | 小程序登录、订阅消息、企微客户联系 |
| 鉴权 | Spring Security + JWT（RuoYi） | 员工用 RuoYi 令牌；学生端 `/app/**` 独立令牌 |
| 接口文档 | springdoc-openapi | `/swagger-ui.html` |
| 管理端 | Vue 3 + Vite + Element Plus + Pinia（RuoYi-Vue3，`zt-abroad-vue`） | JavaScript，沿用 zt-vue 规范 |
| 学生端 | uni-app（Vue 3） | 一套代码输出微信小程序 + H5，独立仓库 |
| 大模型 | 国内已备案大模型 API，兼容 OpenAI 协议 | 一主一备两家，网关可切换 |
| 对象存储 | 腾讯云 COS | 成绩单、简历、报告长图 |
| 部署 | 腾讯云服务器 + Docker Compose（Nginx、应用、PostgreSQL、Redis） | 本地开发见 `docker-compose.yml` |

| 测试 | JUnit 5（选校引擎重点）；PostgreSQL 临时库验证 SQL；Playwright | Playwright 跑 H5 和管理端的端到端测试 |
| 监控 | 日志 + 健康检查、告警推到企业微信群 |  |

> 原方案（Java 21 + MyBatis-Plus + Flyway + TypeScript 管理端、新建工程）已不采用，保留在下面“备选方案”中作为记录。

## 选型理由与备选方案

**为什么是 Java + Vue**

- **审得动：** 代码主要由 AI 写，但安全和关键逻辑要人看得懂。你已有的 zt 工程就是 Spring Boot + Vue 3 + PostgreSQL，经验可以直接复用。
- **AI 写得好：** Java/Spring、Vue/TypeScript 都是公开代码最多的技术栈之一，AI 生成质量稳定。
- **微信生态成熟：** WxJava 覆盖小程序、公众号、企业微信、微信支付。
- **前端统一 Vue：** 管理端和小程序都用 Vue 3，类型定义、接口代码、工具函数可以共用。

**创业期刻意不用的**

| 不用 | 原因 | 何时可能引入 |
| --- | --- | --- |
| 微服务 | 部署和排障复杂，单体 + 模块边界已够用 | 单个模块压力明显时单独拆出 |
| Kafka / RocketMQ | 消息量小，Redis 已够 | 对外输出、多客户并发后 |
| Elasticsearch | PostgreSQL 全文检索 + pgvector 已够 | 院校库上万条且搜索慢时 |
| Kubernetes | 单台服务器足够 | SaaS 多客户后 |
| 自建 / 微调大模型 | 成本高、备案复杂 | 暂不考虑 |

**备选方案**

- **TypeScript 全栈（NestJS 或 Next.js）：** 前后端单一语言，AI 开发更快；但团队积累在 Java，企业级权限、事务、微信 SDK 生态不如 Java 成熟。如果你更熟悉 TypeScript，可以换。
- **新建工程（原方案）：** Java 21 + MyBatis-Plus + Flyway + 多租户，结构更干净；但权限、菜单、日志、代码生成都要重写。已改为沿用 RuoYi（定制输出按独立部署，不需要多租户；学生端鉴权单独加一套过滤器即可）。
- **阿里云替代腾讯云：** 可行；选腾讯云只是因为和微信小程序、企业微信的开通和对接更顺。
