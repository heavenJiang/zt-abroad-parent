## 一、我们如何收集和使用您的个人信息

我们只会出于本政策所述目的、在必要范围内收集和使用您的个人信息。下面按您使用本服务的步骤逐一说明；每一项信息的目的、处理依据、是否敏感及保存期限，汇总在**附录一**。

### （一）打开落地页、阅读并同意本政策

1. 您打开测评落地页时，我们无需您登录。为保障服务正常运行和网络安全，我们的服务器会自动记录**网络访问日志**：IP 地址、访问时间、访问的页面、浏览器或微信客户端类型及版本（User-Agent）。
2. 如您是通过带有**渠道码**的链接或二维码进入（例如某篇文章、某场讲座、某位老用户的推荐码），页面会记录该渠道码，用于统计各推广渠道的效果。
3. 您点击同意本政策后，我们会记录**同意的时间和所同意的政策版本**，并创建一条匿名测评记录。此时该记录只关联一个**设备标识**（由本服务随机生成、保存在小程序本地缓存或浏览器本地存储中的标识，不是您设备的硬件识别码）和渠道码【待技术确认：设备标识的生成方式及是否另收集设备型号、操作系统版本、微信版本、屏幕尺寸等设备信息】。
4. **我们不会读取您设备的 IMEI、MAC 地址、通讯录、相册（除非您主动选择上传文件）、精确位置等信息。**

### （二）填写测评问卷

问卷分为 5 步，每屏不超过 4 题，大部分题目可跳过；您的答案会自动保存，便于您中断后从上次位置继续。我们收集以下**问卷答案和学术背景**：

| 步骤 | 收集的信息 | 是否必填 |
| --- | --- | --- |
| 1 目标 | 目标国家 / 地区、学位、专业方向、计划入学年份 | 必填（用于确定适用的选校规则）|
| 1 目标（建议新增） | **当前所处阶段（高中 / 本科在读 / 已毕业）及年龄段（未满 14 周岁 / 14–17 周岁 / 18 周岁及以上）**【待确认：现有问卷未设计，见第八部分】| 必填 |
| 2 学术 | 本科（或在读）学校名称、专业、均分 / GPA、专业排名 | 学校、专业、均分必填；排名可跳过 |
| 3 语言与标化 | 雅思 / 托福 / 多邻国、GRE / GMAT 等成绩，或“未考 / 预估分” | 可选“未考” |
| 4 经历 | 科研、实习 / 工作、竞赛 / 项目 / 证书的有无、数量、级别、时长、与目标专业是否相关 | 可跳过 |
| 5 偏好 | 预算区间、排名还是就业优先、城市偏好、学制偏好 | 可跳过，默认不限 |

使用目的：

- 计算您的竞争力画像、选校分档（冲刺 / 主攻 / 保底）、差距与提升建议，生成测评报告；
- 根据您输入的学校名称自动带出院校层次，减少您的填写；
- 在您同意顾问联系的前提下，供顾问了解您的背景并为您提供解读（见第九部分）；
- 以去标识化、汇总统计的形式改进问卷和选校规则（见本部分第（八）项）。

**提示：** 预算区间反映您的家庭支出意愿，我们只收集区间而非具体金额，且仅用于筛选和排序学校。我们不会要求您在问卷中填写姓名、身份证件号码或家庭住址。

### （三）上传简历或成绩单（可选）

为减少填写，您可以在“经历”步骤**选择**上传简历或成绩单（PDF 或图片），由系统自动识别并预填问卷，**预填结果须经您确认后才会写入您的测评**。您也可以不上传，直接手动填写，不影响测评和报告。

1. 收集的信息：您上传的**文件本身**，以及从中识别出的学校、专业、均分、课程、经历条目等。文件中可能包含您的姓名、照片、学号、联系方式，甚至身份证件号码等信息。**我们建议您上传前遮盖与测评无关的信息（如证件号码、照片、家庭住址）。**
2. **敏感个人信息：** 由于简历、成绩单可能包含身份证件号码等敏感个人信息，且您可能是未成年人，我们将上传文件**按敏感个人信息处理**，在您上传前通过单独的勾选项取得您的**单独同意**（文案见附录三）。
3. 处理方式：文件存储在私有的对象存储空间中，不公开访问，内部访问使用有效期不超过 10 分钟的临时链接；识别时，系统会通过人工智能网关**先对文本进行去标识化处理**（将姓名、手机号、微信号、身份证件号码等替换为占位符），再交由大模型服务提取字段（见第二部分）【待技术确认：图片或扫描件格式的文件如何在发送大模型前完成去标识化，见律师审阅要点】。
4. 保存期限：原始文件在识别完成后保存 **30 日**后删除；您确认后的问卷字段随测评记录保存【待确认】。

### （四）微信登录并生成报告

1. 生成报告前，我们需要您通过微信授权登录（小程序一键登录；H5 在微信内通过微信网页授权）。我们将获得您在本服务下的 **微信 OpenID**，以及在【运营主体名称】名下微信开放平台账号范围内的 **UnionID**。
2. 使用目的：
   - 为您创建或匹配本服务的用户账号，把您的测评和报告保存到您的账号，便于您再次查看；
   - 识别同一用户的多次测评，避免为您重复建档（我们会按 UnionID 或手机号的加密哈希值合并同一人的记录）；
   - 在您同意的前提下，用于向您发送小程序订阅消息（需您在微信中另行订阅）。
3. 我们**不会**通过登录获取您的微信头像、昵称、好友关系【待技术确认：H5 网页授权仅使用静默授权范围】。
4. **这是生成报告前唯一需要的身份信息；我们不强制要求您提供手机号。**

### （五）查看和分享报告

1. 报告包括：一句话定位、竞争力画像、冲刺 / 主攻 / 保底代表学校及理由、关键短板、补足后可申的项目、下一步建议，以及数据来源与“结果仅供参考，不代表录取承诺”的说明。
2. 您可以生成分享长图。**分享长图默认只显示档位和学校，不显示您的姓名、本科学校和具体均分**；如您主动选择显示更多信息，请注意这些信息将随长图被他人看到。分享长图带有我们的二维码及与您关联的渠道码，用于统计分享带来的新用户，并在您参与“邀请解锁”等活动时为您计算权益。
3. 我们**不会**把您的测评结果告诉通过您的长图或邀请进入的其他用户，也不会把他们的测评结果告诉您。

### （六）预约顾问解读

您可以在报告页预约免费的顾问解读。为安排解读，我们收集**预约信息**：预约的时间段、联系方式（**手机号**）、称呼（可填写昵称）、希望重点了解的问题（可选）、是否有家长一同参与（可选）【待技术确认：预约表单的最终字段】。

- **手机号**用于与您确认预约、发送预约提醒短信、在解读时联系您。手机号在我们的系统中**加密存储**，另存一个不可逆的哈希值用于识别重复记录；员工查看完整手机号需单独权限并留存操作记录。
- 您也可以通过微信“手机号快速验证”组件授权手机号（需经您点击确认）【待技术确认】。
- 提交预约即表示您希望顾问联系您；预约信息仅用于本次解读及后续您同意的联系（见第九部分）。

### （七）添加顾问企业微信

报告页会展示负责顾问的企业微信“联系我”二维码。您主动添加顾问后，我们会通过企业微信获得您作为企业微信外部联系人的**外部联系人标识**以及企业微信按其规则提供的信息（如微信昵称、头像、UnionID）【待技术确认：实际获取的字段】，用于将您的企业微信联系人关联到您的测评记录，使顾问在与您沟通时能看到您的测评结果，为您提供有针对性的解读。

**会话存档：** 本版本不开启企业微信会话存档。如将来开启，我们会依照企业微信官方要求另行明确告知并取得您的同意。

### （八）保障安全、维护服务和改进产品

1. **安全与运维：** 我们会记录网络访问日志、接口调用记录、异常日志，并对测评提交、登录等接口按微信 OpenID 和 IP 地址限制频率，用于防止刷接口、刷 AI 费用、恶意攻击，保障您和其他用户的账号与数据安全。
2. **人工智能调用记录：** 每次调用大模型，我们会记录场景、模型、提示词版本、**去标识化后的输入摘要**、输出、耗时、用量和审核情况，用于追溯“这条结论从哪里来”、核查错误和控制成本。
3. **改进产品与算法：** 我们会对测评数据进行**去标识化或匿名化后**的统计分析，用于校准选校规则、改进问卷和报告。我们不会将可识别您个人身份的信息用于上述目的；**我们不会将您的个人信息提供给大模型服务提供商用于训练其模型。**

### （九）意向度评分与线索管理

在您**同意顾问联系**后，我们会将您的测评记录转为一条咨询线索，供顾问跟进。为合理安排跟进顺序，系统会根据以下因素自动计算**意向度等级（A / B / C）**：计划入学时间、是否有家长参与、是否预约解读、重复测评次数、预算与目标的匹配度；并由人工智能生成仅供顾问内部查看的“线索卡片”（背景摘要、可能的顾虑、建议的沟通话题）。意向度等级只影响顾问联系您的先后，**不影响您能获得的报告内容或服务价格**，顾问可以人工调整。详见第二部分。

### （十）您主动联系我们时

您通过客服、邮箱或企业微信向我们反馈、投诉或行使权利时，我们会收集您提供的联系方式和反馈内容，用于处理您的请求，并按法律要求留存处理记录。

### （十一）征得同意的例外

根据法律法规，以下情形处理您的个人信息无需取得您的同意：为订立、履行您作为一方当事人的合同所必需；为履行法定职责或者法定义务所必需；为应对突发公共卫生事件，或者紧急情况下为保护自然人的生命健康和财产安全所必需；为公共利益实施新闻报道、舆论监督等行为，在合理的范围内处理个人信息；依照法律规定在合理的范围内处理您自行公开或者其他已经合法公开的个人信息；法律、行政法规规定的其他情形。

### （十二）将来新增的功能

签约后的学生 / 家长端、文书、申请、录取结果回填、案例宣传授权等功能会涉及新的个人信息处理活动。我们会在功能上线前更新本政策或另行告知，并就需要单独同意的事项（如录取案例用于宣传、将申请材料提供给境外院校）另行取得您的单独同意。

## 二、自动化决策与人工智能处理

**本部分说明我们如何使用算法和大模型处理您的信息，请您重点阅读。**

### （一）选校引擎：确定性的自动化计算

1. 您的问卷答案由我们自研的**选校引擎**自动计算：先按各项目公开的申请要求进行硬门槛筛选，再按“国家 × 学位 × 专业大类”配置的权重计算综合竞争力，与项目的录取参考线比较后，分为冲刺 / 主攻 / 保底三档，并按您的偏好排序、计算差距。
2. 选校引擎是**规则与统计模型，不使用大模型**，同一份背景每次计算结果一致。引擎使用的权重、参考线由我们的顾问根据经验、项目官方公开信息和录取案例设定，并会随录取结果校准；报告中会说明院校信息的来源与更新日期。
3. **报告只展示档位，不展示录取概率百分比。**

### （二）大模型服务：解析材料与撰写解释

我们使用**中华人民共和国境内已完成备案的生成式人工智能服务**（大模型服务），只用于：

| 场景 | 做什么 | 输出如何使用 |
| --- | --- | --- |
| 报告解读 | 把选校引擎的结果写成报告中的定位说明、每所学校的理由和短板说明 | 在报告页标明“AI 生成”；由顾问**定期抽检**；大模型不可用时使用固定模板文字 |
| 简历 / 成绩单解析 | 从您上传的文件中提取问卷字段 | **您确认后才写入**；解析失败时由您手动填写 |
| 线索卡片 | 为顾问生成背景摘要、可能的顾虑、沟通话题 | 仅顾问内部可见，不向您展示 |

**关于人工审核：** 免费报告中的解读文字为即时生成，为保证您在短时间内看到报告，**发出前不逐份经顾问审核**，而是采用抽检，并经过系统的输出过滤（拦截录取承诺、违规广告用语等）。**顾问向您提供的个性化选校方案、提升建议等建议类内容，由顾问审核确认后才会发送给您。**【待确认：产品文档与开发规范对“报告解读是否须先审后发”口径不一致，见律师审阅要点】

大模型不会决定您的档位，也不会凭记忆回答院校信息；院校要求、截止日等事实只取自我们的院校库，并附有来源。

### （三）发送给大模型前的去标识化

## 六、我们如何保护您的个人信息

1. **传输与存储安全：** 全站使用 HTTPS 加密传输；手机号、身份证件号码等敏感字段加密存储，另存哈希值用于查重；文件存于私有存储空间，只能通过短期有效的临时链接访问。
2. **访问控制：** 员工按角色授权，顾问只能查看分配给自己的线索；界面对手机号等字段脱敏显示，查看全文、导出数据需单独权限并留存操作记录；审计日志保存不少于 6 个月。
3. **去标识化：** 发送给大模型的数据先经去标识化处理；用于算法校准的数据经去标识化或匿名化处理；录取案例与身份信息分开存储。
4. **最小化：** 前三步问卷不要求登录、不要求手机号；分享长图默认隐藏可识别信息。
5. **管理措施：** 我们对接触个人信息的员工进行保密约束和培训，对受托方进行审查与监督。
6. **安全事件处置：** 如发生个人信息泄露、篡改、丢失，我们将立即采取补救措施，按规定向有关主管部门报告，并以推送、短信、邮件或公告等方式告知您事件情况、可能的影响、我们已采取的措施以及您可以采取的减轻风险的措施。

请您理解，互联网环境并非绝对安全，我们将尽合理努力保护您的信息安全。

## 附录四：名词解释

- **个人信息：** 以电子或者其他方式记录的与已识别或者可识别的自然人有关的各种信息，不包括匿名化处理后的信息。
- **敏感个人信息：** 一旦泄露或者非法使用，容易导致自然人的人格尊严受到侵害或者人身、财产安全受到危害的个人信息，包括生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹等信息，以及不满 14 周岁未成年人的个人信息。
- **去标识化：** 个人信息经过处理，使其在不借助额外信息的情况下无法识别特定自然人的过程。
- **匿名化：** 个人信息经过处理无法识别特定自然人且不能复原的过程。
- **自动化决策：** 通过计算机程序自动分析、评估个人的行为习惯、兴趣爱好或者经济、健康、信用状况等，并进行决策的活动。
- **OpenID / UnionID：** 微信为用户在某个小程序或公众号下分配的标识，以及在同一开放平台账号下的统一标识。
- **渠道码：** 测评链接或二维码中携带的编号，用于识别您从哪个推广渠道进入。
- **选校引擎：** 本服务自研的、基于规则与统计模型的选校计算程序，不使用大模型。
