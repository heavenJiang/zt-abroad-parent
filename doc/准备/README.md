以下问题牵涉多个任务卡或产品设计，需要创始人拍板后同步修改相关文档：

2. **AI 审核口径**：已按《架构设计》Agent 表统一为“按 Agent 配置审核策略”（报告解读直接展示 + 抽检，个性化建议类顾问确认后发出），开发规范 14.2 与两个仓库的 `CLAUDE.md` 已同步修改。
3. **隐私政策承诺但 1a 页面清单没有的功能**：注销账号、隐私设置（联系与提醒开关）、「我的测评」、联系我们页；线索「勿联系」标记；图片 / PDF 简历送大模型前先 OCR 再脱敏。需决定是否补入 1a 任务卡（见律师审阅要点末尾表格）。
4. **首批国家与学位**：参数草案按设计文档定为英国、澳洲、新加坡授课型硕士首批（2026-10-14 加入中国香港，草案复制自新加坡），美国硕士其次，日韩德最后；问卷 v1 只覆盖硕士、博士，不含本科（高中生）申请。
