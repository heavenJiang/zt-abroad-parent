# 顾问工作台设计

本页设计机构内部人员（咨询顾问、规划顾问、文案、申请 / 签证专员、主管）每天使用的 Web 工作台，以及企业微信侧边栏。界面描述为交互级线框，视觉稿另行设计。

## 设计目标与交互原则

工作台的目标是让一名顾问**打开一个页面就知道今天先做什么、点一次就能开始做**，AI 提前把初稿和风险提示准备好。

1. **以「人」和「今天」为中心：** 首页是今日待办，不是数据报表；任何学生相关的操作都能从学生档案页完成。
2. **AI 建议一律可采纳、可修改、可拒绝：** 不自动发给学生；修改和拒绝的原因自动回流评测。
3. **少跳转：** 详情用右侧抽屉打开，列表不丢上下文；常用动作在行内完成（改状态、记跟进、指派）。
4. **状态和时限始终可见：** 每个学生都有阶段进度条，每个任务都显示 SLA 剩余时间，超时用颜色 + 文字双重标识。
5. **效率操作：** 全局搜索（学生、项目、任务）；常用快捷键；批量操作（批量分配、批量提醒）。
6. **与企业微信无缝：** 顾问大部分时间在微信里沟通，侧边栏让他们不切系统也能看档案、记跟进。
7. **可配置但有默认：** 列表列、看板阶段、首页卡片可按角色配置，开箱即用。

## 今日工作台（首页）

首页只回答一个问题：**我今天先做什么**。中间是按风险排序的待办，右侧是 AI 助手。

> 图：今日工作台线框 · 待办 + AI 助手（图在在线文档中查看：https://claude.ai/code/artifact/3f423242-8dd1-4136-99ec-c924c5bddfc5）

**交互说明**

- **待办排序：** 已超时 > 即将超时（2 小时内）> 7 天内截止 > AI 待确认 > 其他；同级按影响学生数排序。红点为已超时或高风险，黄点为即将到期。
- **行内动作：** 每条待办右侧是最常用的一个动作（联系、催办、查看、批注、批量确认），点击在右侧抽屉内完成，不离开首页。
- **顶部数字卡：** 点击即筛选下方列表（如只看「SLA 预警」）。
- **AI 助手：** 每天早上和每次待办变化时刷新建议；建议卡可采纳或忽略，采纳即执行（如打开联系抽屉、发出催办草稿）。
- **按角色切换：** 文案老师的首页以「待批注文书」为主，申请专员以「截止日与缺材料」为主，主管默认进入团队看板。

## 线索与商机

咨询顾问的主界面，目标是**高意向线索一个不漏、每次联系都有准备**。

**两种视图**

- **列表视图（默认）：** 按「意向度 → 下次联系时间」排序；列：姓名、意向度 A/B/C、目标国家与学位、测评档位摘要、来源渠道、最后跟进、下次联系、SLA 剩余。行内可直接「记跟进」「改阶段」「转给同事」。
- **看板视图：** 初联 → 首访已约 → 方案已出 → 报价中 → 签约 / 流失。拖卡片改阶段；拖到「流失」弹出必填原因；拖到「签约」跳合同创建。

**线索详情（右侧抽屉）**

| 区域 | 内容 |
| --- | --- |
| 头部 | 姓名、意向度、阶段、来源（哪条内容 / 哪个大使）、负责人、一键加企微 / 拨号 |
| AI 线索卡片 | 背景摘要、测评结果、最可能的顾虑（如「担心均分不够」）、建议的开场话题 |
| 时间线 | 测评、内容浏览、企微会话摘要、通话、跟进记录按时间排列 |
| 下一步 | AI 建议的下一步动作和时间（可一键创建提醒） |
| 首访准备 | 一键生成首访提纲：要确认的信息、可能的异议与回应要点、推荐服务包、初步选校方向 |

**首访后**：上传录音或粘贴记录（须征得客户同意），AI 生成纪要，并把新信息自动更新到背景字段（顾问确认后写入）。

## 学生 360° 档案页

档案页是工作台的核心：**服务小组里的每个人打开同一页，看到同一份事实**，只是默认标签页和可编辑范围不同。

> 图：学生 360° 档案线框 · 阶段条 + 概览 + AI 助手（图在在线文档中查看：https://claude.ai/code/artifact/3f423242-8dd1-4136-99ec-c924c5bddfc5）

**交互说明**

- **阶段进度条：** 显示学生在服务流程中的位置；点击任一阶段看该阶段的任务、产出和完成时间。阶段由任务完成自动推进，也可由主管手动调整。
- **标签页：** 概览 / 背景材料 / 选校 / 文书 / 申请 / 沟通 / 合同。规划顾问默认打开「选校」，文案老师默认「文书」，申请专员默认「申请」。
- **概览四张卡：** 当前风险（自动从截止日、缺材料、要求变更、投诉中汇总）、本阶段任务、定校清单摘要、最近沟通。每张卡可点进对应标签页。
- **背景材料：** 结构化字段（与测评同一套）和文件库；上传成绩单、语言成绩后 AI 解析并提示「有 3 个字段将更新」，确认后写入，并自动重算选校档位。
- **沟通：** 企业微信会话摘要、通话、会议纪要、家长周报按时间线排列，可按「学生 / 家长 / 内部」筛选；内部备注对学生和家长不可见。
- **AI 助手：** 自动带入当前学生的档案，常用提问一键触发；周报等发给家长的内容必须点「发送」才会发出。
- **阶段对应关系：** 档案页的 9 个阶段对应主文档「端到端业务流程」的第 4–12 步（签约之后）；第 1–3 步属于线索阶段，在「线索与商机」里管理。

## 选校工作台

规划顾问在这里把测评结果变成正式方案。界面是**三列看板：冲刺 / 主攻 / 保底**，每张卡片是一个项目。

1. **生成初稿：** 打开学生的选校工作台，系统用最新档案重算一次，给出默认 2 冲 + 4 稳 + 2 保。每张卡片显示：学校 + 项目、排名、学费、截止日、与门槛的差距、档位依据（参考线来源）。
2. **调档：** 把卡片拖到另一列即调档，弹出必填原因（下拉 + 备注，如「该项目今年扩招」）。原因进入算法校准队列。
3. **加减项目：** 右侧「项目库」按国家、专业、排名、预算筛选，拖入即自动算档；不满足硬门槛的给出红色提示但允许加入。
4. **对比：** 勾选 2–4 个项目进入对比视图（要求、学费、学制、就业、文书题目并排）。
5. **生成方案书：** 选择模板（含品牌），AI 生成每所学校的推荐理由和整体策略初稿，顾问编辑后导出 PDF 或推送到学生端。
6. **学生确认：** 学生端可逐校「同意 / 想讨论」；全部确认后方案锁定为「定校清单 v1」，自动生成各校申请任务和文书任务。之后的修改生成新版本并留痕。

项目要求发生变更时，受影响的卡片显示「要求已变更」角标，点开看新旧对比。

## 文书、申请与签证中心

### 文书中心

编辑页为**三栏布局**：左栏素材库（素材卡可拖入大纲），中栏文书正文（学生撰写，支持批注和修订模式），右栏是该校题目要求、字数计数和 AI 批注列表。

| 状态 | 谁在动 | 进入下一状态的条件 |
| --- | --- | --- |
| 素材挖掘中 | 学生 + AI 对话 | 可用素材卡 ≥ 设定数量，文案老师确认 |
| 大纲待确认 | 文案老师审，学生确认 | 学生点「确认大纲」 |
| 学生写作中 | 学生 | 学生提交一版 |
| 批注中 | AI 先批，文案老师再批 | 文案老师发回修改或标为可定稿 |
| 待定稿 | 文案老师 + 规划顾问二审 | 二审通过 |
| 已定稿 | — | 锁定，推送到申请中心 |

列表页按「截止日最近」排序，每篇文书显示状态、第几版、停留天数；学生超过 5 天未提交自动提醒学生和文案老师。

### 申请中心

- **截止日历：** 月视图 / 时间线视图，显示我负责的所有学生的各校各轮截止日，7 天内的标红。
- **材料矩阵：** 行 = 学生 × 学校，列 = 材料（成绩单、语言、文书、推荐信 1/2/3、简历、申请费），格子显示状态色块，点击打开材料或发催促。一眼看出「哪个学生哪个学校还差什么」。
- **递交前检查：** AI 核对网申信息与档案一致性（姓名拼写、生日、均分、学校名称），材料是否满足要求（字数、格式）；通过后申请专员手动递交并上传确认截图。
- **结果录入：** 录取 / 拒绝 / 候补 + offer 文件，录入后自动进入案例库待核验队列。

网申账号密码单独加密保管，查看需二次验证并留痕。系统不自动登录学校网申系统。

### 签证中心

按国家模板生成材料清单和步骤（如 CAS / I-20 等文件、资金证明、体检、预约面签），学生在小程序上传，AI 检查文件是否齐全、是否过期、信息是否一致；顾问复核。各国签证要求以官方最新公布为准，模板纳入「信息更新」流程维护。

## AI 交互规范

全部 AI 功能用同一套组件，让顾问一眼分辨「这是 AI 的建议」并且始终由人拍板。

| 组件 | 样式与行为 |
| --- | --- |
| AI 建议卡 | 固定的 AI 标识 + 浅色底；内容 + 依据（可展开看来源：院校库条目、案例、对话片段）；三个按钮：采纳 / 修改后采纳 / 拒绝（拒绝可选填原因） |
| 生成中状态 | 流式显示，可中断；超过 30 秒提示后台生成完成后通知 |
| 待确认队列 | 首页「AI 待确认」汇总所有等我拍板的 AI 输出（方案、周报、回复草稿），可逐条或批量处理 |
| 草稿标识 | AI 起草、未经人确认的内容带「草稿」水印，不能直接发给学生 |
| 不确定提示 | 检索不到依据或数据过期时，明确显示「没有找到可靠来源」，不给猜测答案 |
| 撤销与历史 | 采纳后 10 秒内可撤销；每条 AI 输出可查看生成时间、模型、提示词版本、经手人 |
| AI 助手面板 | 右侧可收起；自动带入当前页面上下文（当前学生 / 线索 / 文书），支持「帮我写给家长的回复」「这个项目和 XX 比怎么样」等自由提问 |

**反馈闭环**：采纳 / 修改 / 拒绝的比例按功能统计，展示在 AI 平台后台；修改前后的差异进入评测集。

## 企业微信侧边栏与移动端

顾问在企业微信里和学生、家长聊天时，侧边栏自动识别当前客户，显示精简版档案。

| 侧边栏标签 | 内容与动作 |
| --- | --- |
| 客户 | 线索或学生身份、阶段、意向度、测评摘要；未入库的联系人可一键创建线索 |
| 快捷动作 | 记跟进、改阶段、建提醒、发测评链接、发选校方案 |
| AI 回复助手 | 读取最近会话（会话存档须征得客户同意），生成 2–3 个回复草稿；事实问题从院校库取答案并附来源；顾问点「插入」后自己发送 |
| 素材 | 话术库、案例卡片、内容链接，点击即发 |

**移动端**：不做单独 App，用企业微信内的 H5 工作台，只提供「今日待办、查学生、记跟进、审批」四个高频功能；文书编辑、选校调档等重操作只在 Web 端。

## 管理者视图、通知与权限

**团队看板（主管首页）**：顶部一行核心指标（本月新线索、签约、在服学生、SLA 达成率）；下方按顾问列出负载（在服学生数、逾期任务数、本周到期截止日），点进任一顾问可看其待办并一键转派；风险列表集中显示「截止日 7 天内仍缺材料」「家长投诉」「连续超时」的学生。

**通知规则**

| 事件 | 通知谁 | 渠道 |
| --- | --- | --- |
| 新线索分配（A 类） | 负责顾问 | 企业微信 + 站内，即时 |
| 任务即将超时 / 已超时 | 负责人；超时后加主管 | 企业微信 |
| 截止日前 14 / 7 / 3 天 | 申请专员、学生 | 企业微信 / 小程序订阅消息 |
| 项目要求变更 | 定校清单含该项目的顾问和学生 | 站内 + 企业微信 |
| AI 待确认超过 24 小时 | 对应顾问 | 站内 |
| 家长投诉 / 差评 | 负责顾问 + 主管 | 企业微信，即时 |

每人可设置免打扰时段；非即时类通知合并为每日摘要。

**权限在界面上的体现**

- 无权限的导航和按钮直接隐藏，而不是置灰。
- 手机号、证件号、合同金额等默认脱敏显示（如 138****5678），有权限者点「查看」才显示全文并留痕。
- 导出需填写用途，超过设定条数走主管审批，导出文件带导出人水印。
- 员工停用时，系统强制进入「交接」界面，将其线索、学生、任务转给接手人后才能停用。

## 分期上线范围

| 阶段 | 上线内容 | 工作室先用什么 |
| --- | --- | --- |
| 阶段一（底座 + 获客） | 今日工作台、线索与商机、学生档案（概览 + 背景 + 沟通）、选校工作台、院校库查询、企业微信侧边栏（客户 + 快捷动作）、AI 建议卡与待确认队列 | 全部 |
| 阶段二（交付 + AI 平台） | 任务工单与 SLA、文书中心、申请中心、签证中心、AI 回复助手、内容中心、团队看板 | 全部 |
| 阶段三（产品化） | 角色与导航自定义、品牌模板、导出审批、多校区切换、租户管理员设置中心 | 按需 |

开发前建议先用可点击原型让顾问试用一周，重点验证「今日工作台」的排序和「选校调档」的操作是否顺手。
