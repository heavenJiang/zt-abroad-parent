# 冷启动与种子用户

本页设计工作室上线后前 90 天怎么拿到第一批学生用户，并用他们验证测评、内容和转化链路。所有数字都是初始假设，上线后按真实数据调整。

## 冷启动目标

前 90 天只证明一件事：**「内容 → 免费测评 → 顾问解读 → 签约」这条链路能跑通，而且每签一单的成本可以接受**。不追求粉丝量和曝光量。

| 环节 | 90 天累计目标（假设） | 说明 |
| --- | --- | --- |
| 开始测评 | 1,500 人 | 内容和渠道带来的总量 |
| 完成测评拿到报告 | 1,000 人 | 完成率约 65% |
| 加微信 / 预约解读 | 200 人 | 留资率约 20% |
| 完成顾问首访 | 80 人 | 到访率约 40% |
| 签约 | 8–12 人 | 首访签约率约 10%–15% |

这些比例没有行业数据支撑，只用来排计划。上线第一个月的真实比例出来后，用它替换这张表，并反推需要多少测评量。

## 切入人群

第一批种子用户只服务一个窄人群：**申请英国、澳洲、新加坡授课型硕士的国内本科大三、大四学生**（具体国家按工作室主做方向调整）。

| 判断维度 | 为什么适合冷启动 |
| --- | --- |
| 需求量 | 这是中国学生出国读硕的主流方向，人群大、内容好做 |
| 算法可靠度 | 录取标准化程度高（院校层次 + 均分为主），规则版算法就能给出较准的结果 |
| 决策周期 | 从开始了解到签约通常在一年内，90 天内能看到签约信号 |
| 测评意愿 | 学生最关心「我这个均分能申哪些学校」，正好是测评回答的问题 |
| 触达成本 | 集中在高校和小红书，可以用内容和校园渠道低成本触达 |

**暂不作为冷启动重点**：美国本科和博士（录取更看软背景，规则版算法不准）、日本韩国德国（申请路径特殊，如联系导师、APS）、高中生（涉及未成年人，决策在家长，周期长）。这些人群在案例积累后再放开。

**种子用户画像卡**：大三学生，双非或 211，均分 80–88，还没考语言或刚考完；在小红书搜「英国硕士选校」；担心「均分不够」和「被中介坑」；家长出钱但不懂申请。

## 上线前准备

冷启动最怕的是「用户来了，测评不准、内容接不上」。上线前先把下面四件事做到可用。

- [ ] **院校数据：** 切入人群对应的 200–300 个常申项目录入完成，每条有来源和核对日期。
- [ ] **案例积累：** 把顾问过往经手的案例按「录取案例库」结构整理 50–100 条（脱敏；来自前雇主的案例要注意保密义务，只用顾问自己可合法使用的信息），用来设定参考线。
- [ ] **测评内测：** 找 20–30 个已知结果的学生（已录取的学长学姐、熟人）用他们当年的背景测一遍，对照真实结果校准档位；再由顾问盲评 20 份报告。
- [ ] **内容储备：** 上线前写好 20–30 条内容（打法见下一节「种子用户获取」里的「内容平台」），保证上线后前一个月日更。
- [ ] **转化工具：** 企业微信、预约时段、线索看板、顾问解读话术和报价方案就绪。
- [ ] **合规：** 隐私政策、用户协议、案例授权模板、广告用语自查。

## 种子用户获取

按「信任从近到远」分三圈推进：先用熟人验证产品，再用社群和内容验证获客，最后才花钱放量。

| 圈层 | 目标量 | 渠道 | 具体做法 | 主要成本 |
| --- | --- | --- | --- | --- |
| 第一圈：熟人 | 0 → 50 人测评 | 顾问个人微信、前客户、亲友子女、已录取学长学姐 | 邀请成为「创始体验官」，免费测评 + 免费 30 分钟解读，换取一次 15 分钟反馈访谈 | 顾问时间 |
| 第二圈：社群与内容 | 50 → 500 | 小红书、视频号直播、知乎、高校学生社群、学长学姐转发 | 见下方「内容平台」和「校园与社群」 | 内容人力、少量礼品 |
| 第三圈：合作与投放 | 500 → 1,500+ | 语培老师 / 小机构互导、校园讲座、小额信息流投放 | 只对第二圈已验证有效的内容和人群加投入 | 分成、投放费 |

**内容平台**

- **小红书（主阵地）：** 用顾问个人账号做 IP，比机构号更容易被信任。三类内容轮换：「同背景能申哪些学校」（如「双非 85 分的英国选校清单」）、案例拆解、选校误区。每条内容的结尾都是「想知道自己的定位可以测一下」。各平台对站外导流有限制，引导方式按平台当前规则（如私信、群聊、平台允许的组件）做，避免限流或封号。
- **视频号直播：** 每周一场「现场帮你选校」，观众在直播间测评，顾问挑 3–5 份报告公开解读（先征得同意并隐去个人信息）；视频号可以直接跳转小程序。
- **知乎：** 回答长尾问题（「XX 专业跨申 YY 需要什么」），流量慢但长期有效。

**校园与社群**

- **校园大使：** 在 5–10 所目标高校各招 1–2 名已录取的大四学生或在读研究生，按带来的有效测评和签约给奖励；提供他们可用的内容和专属二维码。校园推广须遵守学校管理规定。
- **申请季陪伴群：** 按入学年份建群（如「2027 英国硕士申请群」），每周一次答疑和信息更新，群里的报告分享带来自然增长。
- **学长学姐分享会：** 用已录取的种子用户做线上分享，内容真实、成本低。

**合作互导**：找与工作室不竞争、但人群重合的伙伴——雅思 / 托福老师和小型语培机构、背景提升（科研、实习）机构。给对方一个带专属标识的测评入口，测评发现语言或背景短板时反向推荐给对方（学生同意后），签约按条分成。这也是未来 B2B2C 产品的雏形。

## 钩子与激励设计

激励只奖励「对转化有用的行为」（完成测评、预约解读、带来新测评、签约），不奖励单纯的关注和点赞。

| 钩子 | 给谁 | 用来做什么 |
| --- | --- | --- |
| 免费选校测评 + 报告 | 所有人 | 主钩子，换取微信登录和背景数据 |
| 前 100 名「创始体验官」 | 第一圈和早期用户 | 免费 30 分钟顾问解读 + 签约折扣，换取一次反馈访谈 |
| 分享解锁 | 拿到报告的用户 | 邀请 2 位同学完成测评，解锁完整选校列表或一次文书素材诊断 |
| 重新测评提醒 | 暂不签约的线索 | 语言出分、均分更新后重测，重新激活 |
| 老带新奖励 | 已签约学生 | 推荐同学签约后双方各得服务抵扣或现金奖励 |
| 校园大使奖励 | 校园大使 | 按有效测评和签约阶梯计酬 |
| 合作分成 | 语培、背景提升伙伴 | 按签约分成，双向互导 |

防刷：同一微信 / 手机号只算一次有效测评；测评时长过短或背景明显乱填的不计奖励；奖励规则公开并符合营销活动相关规定。

## 种子用户运营

种子期的每个用户都值得人工对待：他们既是线索，也是产品的测试员。

1. **24 小时内人工触达：** 每个完成测评并加微信的用户，顾问当天发一条针对其报告的个性化消息（线索卡片自动提供话题）。
2. **体验官群：** 创始体验官进一个小群，新功能先在群里试，提意见被采纳的给小奖励。
3. **每周 5 个反馈访谈：** 问三个问题——测评结果和你的预期一致吗？报告里哪部分最有用？什么让你愿意 / 不愿意和顾问聊？
4. **两周一次迭代：** 把反馈和漏斗数据合并，每两周改一版问卷、报告或话术，并在体验官群里公布改了什么。
5. **流失回访：** 首访后没签约的，记录原因（价格、信任、时机、选了别家），每月统计一次。

## 90 天执行计划

上线前准备 4 周，上线后 13 周分三段；每段结束先过门槛，过不了就停在本阶段继续改，不提前花钱放量。

> 图：90 天计划 · 4 个阶段，3 个门槛（图在在线文档中查看：https://claude.ai/code/artifact/3f423242-8dd1-4136-99ec-c924c5bddfc5）

「有效渠道」指：连续 4 周稳定带来测评，且至少产生过签约或高意向线索。放量阶段只对这些渠道加投入。

## 验证指标与调整规则

每周一看一次漏斗，哪一环低于下限就只改哪一环，一次只改一个变量。

| 环节 | 指标 | 低于下限时（假设值） | 优先尝试 |
| --- | --- | --- | --- |
| 内容 → 测评 | 每条内容带来的测评数 | 连续 2 周接近 0 | 换选题类型（案例拆解通常比干货更容易引发测评）；把测评入口提前 |
| 开始 → 完成 | 测评完成率 | < 50% | 缩短问卷，能从简历解析的不再让人填；显示进度条 |
| 报告 → 留资 | 加微信 / 预约率 | < 10% | 报告里的「差距」写得更具体，让人想问「那我该怎么办」 |
| 预约 → 首访 | 到访率 | < 30% | 预约后当天确认、提前 1 小时提醒；提供更多时段 |
| 首访 → 签约 | 签约率 | < 8% | 复盘流失原因；调整服务包（如增加半 DIY 套餐）或话术 |
| 测评质量 | 顾问改档率、用户「不准」反馈 | 改档率 > 30% | 调整参考线和权重，先修改档最多的项目 |
| 渠道效率 | 各渠道每签一单成本 | 超过其他渠道 2 倍 | 减少投入，把人力转到效果好的渠道 |

**90 天到期的决策**：链路跑通且每单成本可接受 → 按「分阶段路线」进入放量和阶段二；测评有人用但不转化 → 问题在报告和顾问环节；测评没人用 → 重新选切入人群或钩子。

## B 端种子客户与主要风险

**B 端种子（产品化阶段再启动）**：冷启动期的合作伙伴就是第一批 B 端客户候选。已经在用专属测评入口的语培老师和小机构，可以升级为「自有品牌的测评组件」试用客户；同行工作室通过顾问圈子结识，先提供 3 个月免费试用换反馈和案例。第一批 3–5 家即可，重点是验证多租户和配置能力，不是收入。

**主要风险**

| 风险 | 应对 |
| --- | --- |
| 内容平台限流或封号（导流违规） | 按各平台规则引导；多平台并行，不压在一个账号上 |
| 冷启动期测评不准，第一批用户传出差评 | 上线前用已知结果校准；只展示档位；顾问解读兜底 |
| 顾问时间被免费解读占满 | 解读只给意向度 A/B 类；C 类进申请季陪伴群、直播统一解答 |
| 申请季节奏不对（上线时学生已签完） | 上线时间对准大三下学期到大四上学期的咨询高峰 |
| 校园推广被学校限制 | 以线上社群和学长学姐分享为主，线下活动经学校或社团正式合作 |
| 使用前雇主的案例或客户资料引发纠纷 | 只用顾问可合法使用、已脱敏的信息；不导入前雇主的客户名单 |
