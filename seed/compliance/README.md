# 合规词表草案（M0-10）

> AI 草拟，**待创始人确认、律师审阅**；确认前不作为上线依据。说明与待确认问题见 `doc/准备/M0-10-营销日历剧本与合规词表说明.md`。
> 使用方：M6-03 `compliance_checker`（导入为配置，管理端可增删，不写死在代码里）。

## 格式

与网关输出过滤词表（`zt-abroad/src/main/resources/prompts/_filters/*.txt`）一致：

- 每行一个词；匹配时忽略大小写与空白；
- `#` 开头为注释，`# 类别：xxx` 为类别名称；
- `!` 开头为例外短语：匹配前先从文本中去掉（如 `!第一年` 让“第一年学费”不命中“第一”）。

`patterns.txt` 是制表符分隔的正则规则，网关词表不支持，由 M6-03 实现。

## 与网关输出过滤的关系

`ad_banned.txt`、`admission_promise.txt` 是现有网关词表的扩充版，网关对所有 Agent 输出生效（含报告解读）。创始人确认后，这两个文件替换 `_filters` 下的同名文件。

其余类别只对**对外发布的内容和营销消息**生效，按目标平台选择，由 `compliance_checker` 加载，**不放进网关**：例如“公众号”“小程序”在服务号消息里是正常用语，只在小红书稿件里才算导流。
