# 国内高校层次种子数据（cn-university）

供 `abr_cn_university`（架构设计中的 `cat_cn_university`，按《00-RuoYi落地对照》改为 `abr_` 前缀）导入。问卷用它把学生填写的本科院校自动带出层次。原设计中的管理端 `/catalog/cn-universities` 与学生端 `/cn-university/search`，按落地对照分别落在 `/abroad/<资源>` 与 `/app/**` 下，具体路径在 M2-03 任务卡中确定。

- 文件：`cn_university.csv`，UTF-8（无 BOM），首行为表头，逗号分隔，标准 CSV 引号规则。
- 规模：155 行 = 147 所校本部（即 2022 年第二轮双一流全部建设高校）+ 8 个分校区。
- 核对说明与抽查清单：`doc/准备/M0-07-国内高校层次说明.md`。

## 列说明

| 列 | 说明 |
| --- | --- |
| `name` | 现用正式中文全称，作为唯一键（导入用 `on conflict (name)`）。多校区独立办学的用名单原写法，如 `中国石油大学（华东）`，括号为全角 |
| `aliases` | 简称、英文缩写、曾用名、并入院校旧名，`\|` 分隔，供模糊搜索。**部分简称有意多校共用**（`西大`、`华农`、`宁大`、`JNU`），搜索时应返回多个候选让学生选择，不要自动带出 |
| `province` | 校本部所在省级行政区简称（如 `北京`、`广西`、`内蒙古`），不带“省/市/自治区” |
| `city` | 校本部所在城市，不带“市” |
| `is_c9` | 0/1，C9 联盟成员 |
| `is_985` | 0/1，985 工程高校 |
| `is_211` | 0/1，211 工程高校 |
| `is_double_first_class` | 0/1，2022 年第二轮“双一流”建设高校 |
| `tier` | 取最高层次：`C9` > `985` > `211` > `双一流` > `双非` |
| `source` | 该校所属名单，多个用 `;` 分隔，带名单名称与年份；分校区行附加 `分校区随母校` |
| `note` | 更名、合并、多校区、易混别名等说明。包含 `待核对` 的行需人工确认后再删去该标记；以 `分校区` 开头的行为分校区 |

层次之间是包含关系：C9 ⊂ 985 ⊂ 211 ⊂ 双一流（2022 年名单中 211 高校全部在列）。

## 来源名单

| 层次 | 名单 | 年份 / 状态 |
| --- | --- | --- |
| C9 | 九校联盟（C9 League）成员 | 2009 年成立；为高校联盟，非教育部名单，9 所 |
| 985 | 教育部“985 工程”学校名单 | 2011 年教育部公开名单，39 所；此后不再增补，2015 年起统筹并入“双一流” |
| 211 | 教育部“211 工程”学校名单 | 教育部公开名单（2008 年后不再增补）；含 3 所军队院校（国防科技大学、海军军医大学、空军军医大学）。多校区高校计 1 所时为 112 所，常见“116 所”是把中国矿业大学、中国石油大学、中国地质大学、华北电力大学各计 2 所 |
| 双一流 | 教育部、财政部、国家发展改革委《第二轮“双一流”建设高校及建设学科名单》 | 2022 年 2 月公布，147 所（矿大、石大、地大的北京与异地校区分别计数）；首轮 2017 年为 137 所，已被第二轮替代 |

本数据按记忆整理，导入前须由人对照上述官方名单原文核对（见说明文档中的抽查清单）。

## 双非院校的处理

**双非不入表，默认双非。** 层次表只列 147 所双一流高校及其分校区。问卷中：

1. 学生输入校名 → 调国内高校模糊搜索接口，匹配全称与别名；
2. 命中 → 带出 `tier`，学生确认；
3. 未命中 → 学生仍可提交手填校名，`tier` 记为 `双非`，同时记下原始校名，供后续补录别名或纠错。

注意：独立学院及其转设院校（如原“四川大学锦江学院”、原“吉林大学珠海学院”）名称里带有名校全称，**不继承母校层次**，是双非。模糊搜索实现时应以全称或别名精确匹配为准，不能用“包含母校名”判定层次。若后续海外院校认可名单需要细分双非（如区分公办本科、独立学院、专升本），再另建一份名单，不改本表结构。

## 分校区

设计文档对分校区没有规定，本表按以下默认处理：异地办学、招生代码单列的分校区作为**独立行**，层次与四个标志位继承母校，`note` 以 `分校区，继承母校（…）层次` 开头。同城或同名校区（如中山大学珠海校区、山东大学青岛校区）不另列。

已列 8 个：哈尔滨工业大学（威海）、哈尔滨工业大学（深圳）、山东大学（威海）、东北大学秦皇岛分校、大连理工大学盘锦校区、北京交通大学威海校区、中国石油大学（北京）克拉玛依校区、华北电力大学（保定）。

中国矿业大学 / 中国石油大学 / 中国地质大学的北京与异地两校在双一流名单中各自单列，按独立高校各占一行，不算分校区。

## 更新流程

1. **触发：** 教育部公布新一轮双一流名单、高校更名或合并、管理端或问卷发现未命中的校名 / 别名。
2. **修改：** 只改 `cn_university.csv`。改名时把旧名加入 `aliases`，`name` 换成新全称，`note` 写明更名年份。新增别名直接追加。
3. **校验：** 运行计数与重复检查（C9=9、985=39、211 计 1 所为 112、双一流=147，校名不重复，tier 与标志一致，跨校重复别名只出现在已知的易混列表里），结果写进 M0-07 说明文档或对应任务卡。
4. **人工核对：** 改动行逐条对照官方名单原文，确认后删除 `待核对`。
5. **导入：** 按落地对照不用 Flyway，由 M2-03 生成可重复执行的增量脚本 `sql/abroad/update_<yyyyMMdd>_<内容>.sql`（`insert ... on conflict (name) do update`），写入 `abr_cn_university`（表结构按 RuoYi 口径：`xxx_id bigserial`、审计字段，不加 `tenant_id`）。管理端编辑过的别名应合并，不能被种子覆盖，具体合并规则在 M2-03 任务卡中确定。
6. **影响：** 层次变化会改变测评门槛均分，已完成的测评结果不回溯，新测评按新表计算。
